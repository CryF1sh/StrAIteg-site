# СтрAIтег для вендоров и интеграторов

> Платформа для вендоров, интеграторов и дистрибьюторов промышленного оборудования: по запросу клиента пишет ТЗ, подбирает оборудование из каталога вендора и собирает ТКП по его шаблону с помощью ИИ. Дополнительно приводит заявки от производств на роботизацию и промышленное оборудование. Первый месяц и 100 запросов бесплатно.

СтрAIтег (ООО «Архада», Москва) помогает вендорам находить клиентов на промышленное оборудование и автоматизирует пресейл: инженеру не нужно 3–5 часов разбирать запрос.

## Что делает платформа
- Автоматизация ТКП: ТЗ, подбор позиций из каталога и ТКП по шаблону вендора за минуты.
- Подбор оборудования по ТЗ: позиции из каталога вендора с процентом соответствия и альтернативами.
- Заявки от производств: клиенты для вендоров, клиенты для интеграторов, заявки на роботизацию и промышленное оборудование.
- Источники по каждой цифре в обосновании для клиента.

## Условия
- Пилот: 0 ₽, первый месяц, до 100 запросов, без обязательств.
- Подписка: от 99 000 ₽ в месяц; 3 тарифа: Базовый, Профессиональный, Корпоративный. При оплате за 3 месяца дешевле.
- Комиссия 1% только со сделок с клиентами, которых привёл СтрAIтег. За своих клиентов комиссии нет. Нет сделки — нет комиссии.
- Интеграция с CRM, ERP и MES через REST API на Профессиональном тарифе.
- Подключение: каталог, шаблон и примеры ТКП в любом виде; запуск за 14 дней.
