# Сайт СтрAIтег: лендинги для производств и вендоров

Статический сайт без сборки: загрузите содержимое папки в корень домена `straitegist.ru`.

## Структура

```
index.html            — лендинг для производств (главная, бесплатно)
vendors/index.html    — лендинг для вендоров и интеграторов (/vendors/)
privacy/index.html    — шаблон политики обработки ПД (текст должен подготовить юрист)
assets/styles.css     — стили обеих страниц (цвета и шрифты из дизайн-системы)
assets/site.js        — демо, форма заявки в 2 шага, цели Метрики, мобильное меню
assets/logo.svg       — официальный логотип для тёмного фона
assets/favicon.svg    — иконка сайта
assets/og-plant.png   — превью для мессенджеров, главная (1200×630)
assets/og-vendor.png  — превью для мессенджеров, /vendors/
assets/fonts/         — Montserrat (локально, без Google Fonts)
api/lead.php          — приём заявок: Telegram + пересылка в CRM
api/.htaccess         — закрывает доступ к логу заявок
robots.txt, sitemap.xml
```

## Перед запуском: 4 обязательных шага

### 1. Заявки (Telegram и/или CRM)

Форма отправляет JSON на `/api/lead.php` (адрес задан в `assets/site.js`, `CONFIG.FORM_ENDPOINT`).

Нужен хостинг с PHP 7.4+ и curl. Задайте переменные окружения (или впишите значения в начало `api/lead.php`):

| Переменная | Что это |
|---|---|
| `TG_BOT_TOKEN` | токен бота от @BotFather |
| `TG_CHAT_ID` | id чата или группы, куда падают заявки (добавьте бота в группу) |
| `CRM_WEBHOOK_URL` | необязательно: входящий webhook amoCRM / Bitrix24 / n8n, туда уходит весь JSON |

Если PHP нет, впишите в `FORM_ENDPOINT` webhook CRM или n8n напрямую. Он должен принимать POST с JSON и разрешать CORS для `https://straitegist.ru`.

Форма двухшаговая. Оба шага приходят с одинаковым `lead_id`, поэтому в CRM второй шаг можно склеить с первым.

Поля шага 1: `contact`, `messenger` (telegram | max | whatsapp | phone | email), `task` (производства), `company` (вендоры), `interest` (`sample`, если человек пришёл по кнопке «Скачать пример»).
Поля шага 2: `name`, `company`, `region`, `role` (производства) / `role`, `name`, `position`, `catalog` (вендоры).
Всегда приходят: `audience` (plant | vendor), `step`, `page`, `referrer`, `utm` (+ `yclid`), `sent_at`.

### 2. Яндекс.Метрика

В `<head>` **обеих** страниц (`index.html`, `vendors/index.html`) замените `window.YM_ID = 0;` на номер счётчика. В Метрике создайте JavaScript-цели:

| Цель | Когда |
|---|---|
| `cta_click` | клик по любой оранжевой кнопке |
| `demo_preset` | выбор примера в демо |
| `demo_cta` | клик по кнопке под результатом демо |
| `sample_download` | клик «Скачать пример подбора (PDF)» |
| `form_step1` | заявка отправлена (основная конверсия) |
| `form_step2` | заявка дополнена |
| `faq_open` | открыт вопрос в FAQ |

### 3. Заполнить реальные данные

На сайте жёлтым выделены места, которые нужно заполнить: `[N]`, `[ИНН]`, `[ОГРН]`, `[срок]`, результат кейса, цитаты. Найти их все:

```
grep -rn 'class="ph"' index.html vendors/index.html
```

После заполнения уберите у этих элементов класс `ph`, иначе текст останется жёлтым.

Проверьте, что эти обещания соответствуют реальности: «подбор за 1 рабочий день», «вендоров подбираем по номенклатуре, референсам и региону», «данные не используются для обучения», «контакт получают только выбранные поставщики», «оплата не влияет на выдачу».

### 4. Почта и политика

Заведите ящик `info@straitegist.ru`. Он указан в контактах, футере и как запасной адрес при сбое формы.
Текст `privacy/index.html` нужно подготовить по 152-ФЗ.

## Что ещё можно сделать

- Пример подбора в PDF: сейчас кнопка «Скачать пример подбора» ведёт к форме (лид-магнит: файл получают за контакт). Когда PDF будет готов, его можно отправлять из бота или CRM автоматически по полю `interest = sample`.
- A/B-тест на `/vendors/`: «от 99 000 ₽» на странице против «прайс только за контакт».
- Иконки (Material Symbols) пока грузятся с Google Fonts. Если нужно убрать все внешние запросы, скачайте шрифт в `assets/fonts` и поменяйте ссылку в `<head>`.
- Кнопка «Войти» ведёт на `https://user.straitegist.ru/?role=plant|vendor`.
